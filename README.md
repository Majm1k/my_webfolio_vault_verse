# Портфолио продуктового дизайнера

Одностраничный сайт. Чистые HTML, CSS и ES-модули — без фреймворков,
сборщика и npm-зависимостей в продакшене. GitHub Pages отдаёт файлы как есть.

Ветка `main`, папка `/` (root). `.nojekyll` отключает обработку Jekyll.

## Структура

```
index.html
css/   tokens.css · base.css · components.css · sections.css
js/    carousel.js · flip-cards.js · card-overlay.js
       accordion.js · reveal.js · hero-marquee.js · main.js
fonts/ Inter, три поднабора woff2
img/   hero/ · behance/ · icons/ · favicon.svg · og.png
files/ rezume.pdf
```

Документы проекта: [PLAN.md](PLAN.md) — секции и порядок работы,
[TOKENS.md](TOKENS.md) — цвет, типографика, сетка, кривые, длительности.

## Локальный просмотр

Модули ES не работают по `file://` — нужен любой статический сервер:

```sh
python3 -m http.server 8000
```

## Изображения

Исходники из репозитория пережаты в WebP: лента до 760px по ширине,
обложки Behance до 2000px. 7,3 МБ превратились в 456 КБ, первый экран
грузит 102 КБ вместо 4,4 МБ.

`img/hero/` — порядок ленты слева направо, как на макете:
`1-smartway` · `2-x64` · `3-wowcam-2` · `4-x54-dual` · `5-avtouragan`.

`img/behance/` — `1-task-management-ultra` · `2-apple-clock` ·
`3-food-delivery` · `4-music-player` · `5-task-manager`.

`img/icons/` — стикеры: `cursor.png` у заголовка первого экрана,
`check.png` у «Больше, чем просто факты», `star.png` у FAQ.

## Прогрессивное улучшение

Без JavaScript страница читается целиком: карусели превращаются в обычную
горизонтальную прокрутку, обороты карточек и раскрытое содержимое выводятся
как текст, FAQ работает нативным `<details>`. JS добавляет только стрелки
каруселей, переворот и раскрытие.

Появление при скролле прячет элементы только после того, как наблюдатель
подключился, и через 1.6s показывает принудительно, если он не сработал:
украшение не может скрыть текст насовсем.
