# PLAN.md

Одностраничное портфолио продуктового дизайнера.
Чистые HTML / CSS / ES-модули, без сборки. Деплой — GitHub Pages, ветка `main`, папка `/`.

---

## 1. Файловая структура

```
index.html
css/
  tokens.css        переменные: цвет, типографика, сетка, кривые, длительности
  base.css          reset, html/body, типографические классы, .container, утилиты
  sections.css      раскладка семи секций
  components.css    карточки, карусели, кнопки, чипы, аккордеон, оверлей
js/
  carousel.js       стрелки + границы прокрутки (общий для трёх блоков)
  flip-cards.js     переворот карточек блока «Факты»
  overlay.js        полноэкранный оверлей блока «Больше, чем просто факты»
  accordion.js      FAQ
  reveal.js         IntersectionObserver, появление при скролле
  hero-marquee.js   пауза по ховеру, драг, reduced-motion (сама лента — на CSS)
img/
  hero/             карточки ленты первого экрана
  behance/          обложки проектов Behance
  og.jpg, favicon
files/
  rezume.pdf        «Портфолио PDF»
PLAN.md  TOKENS.md  README.md
.nojekyll
```

Пути к ресурсам относительные (`img/hero/1.jpg`). Подключение JS — `<script type="module">`.
Без JS страница читается целиком: карусели превращаются в обычную горизонтальную
прокрутку, оборот карточек и оверлей раскрыты как текст, FAQ — открытые `<details>`.

## 2. Секции

Порядок сверху вниз, как на макете. Семь блоков.

### S1 — Hero
Фон чёрный. Сверху лента карточек проектов (NEOLINE / G-TECH / АВТОУРАГАН),
непрерывная автопрокрутка, центральная карточка крупнее, боковые уменьшены
и уходят за края. Ниже — H1 «Рузайкин Дмитрий» с курсором-иконкой и лид в 4 строки.
Ширина ленты — `--hero-max` (1680px), ширина текста — `--content-max` (1260px).
Автопрокрутка на CSS-трансформах, набор карточек продублирован в разметке.

### S2 — «С дизайнером дела идут лучше. Факты.»
Фон светло-серый. «Факты.» — маркер голубым.
Карусель тёмных карточек без изображений. Лицевая сторона: надзаголовок `NEOLINE`,
короткий заголовок, круглая кнопка «+» справа внизу. Клик — переворот по оси Y
на месте, без перекрытия страницы. Оборот: развёрнутый текст + кнопка возврата.
Несколько карточек могут быть перевёрнуты одновременно.

### S3 — «Больше, чем просто факты.»
Фон тёмно-серый, у заголовка иконка-галочка. Карусель карточек крупнее, чем в S2,
разной темы: тёмные и светлые. Клик — полноэкранный оверлей поверх страницы,
кроссфейд по разделу «Оверлей» референса, содержимое каскадом.
Закрытие: крестик, Escape, клик по фону. Ловушка фокуса, возврат фокуса на карточку.

### S4 — «Еще больше на Behance.»
Фон чёрный. Карусель широких карточек с обложками проектов и чипом-тегом
в левом верхнем углу. Под обложкой — название, описание, ссылка «Read the story ›».
Раскрытия нет: вся карточка — внешняя ссылка, `target="_blank" rel="noopener noreferrer"`.
Только ховер.

### S5 — Принципы
Фон белый. Три колонки в ряд: нумерация `01 / путь`, `02 / скорость`, `03 / метрики`
мелким акцентным шрифтом, крупный заголовок, мелкая подпись.
На ≤734px — в столбец.

### S6 — FAQ «Остались вопросы?»
Фон светло-серый. «вопросы?» — маркер розовым, справа иконка-звезда.
Аккордеон на восемь вопросов из `content.md` (список на макете устарел).
Разметка `<details>/<summary>`, высота анимируется через `grid-template-rows`
на обёртке контента; сам аккордеон работает и без JS.

### S7 — Футер «Связь и дополнительная информация.»
Фон чёрный. Четыре кнопки-ссылки в ряд:
Telegram ↗ · Email ↗ · Behance ↗ · Портфолио PDF (скачивание файла из репозитория).
На ≤734px — в столбец.

## 4. Технические решения

**Карусели.** Одна реализация на три блока. Прокрутка нативная:
`overflow-x: auto`, `scroll-snap-type: x mandatory`, `scroll-snap-align: center`,
`scrollbar-width: none`, `scroll-padding` от прижима контента.
JS отвечает только за кнопки: `scrollBy` на ширину карточки и блокировка стрелок
на краях (`scrollLeft`, `scrollWidth`, `clientWidth` + запас в 1px).
Появление стрелок — `100ms linear`.

**Переворот (S2).** `transform-style: preserve-3d` на внутренней обёртке,
`backface-visibility: hidden` на обеих гранях, `rotateY(180deg)` на обороте.
Состояние — атрибут `data-flipped` на карточке; несколько одновременно.
Высота карточки фиксированная, чтобы грани совпадали.

**Оверлей (S3).** Один общий `<div class="overlay">` в конце `<body>`,
контент карточек переносится в него, либо оверлей на карточку — решается
на сборке. Блокировка скролла — `position: fixed` на `body` с компенсацией
`scrollbar-gutter`, чтобы контент не дёргался. Фокус: сохранить `activeElement`,
перевести в оверлей, при закрытии вернуть. `inert` на основном содержимом.

**Появление при скролле.** `IntersectionObserver`, `{ once: true }`,
атрибут `data-reveal`, задержка между элементами — inline `--reveal-index`.
Контейнеру `padding-bottom: 30px; margin-bottom: -30px`.
Только там, где объясняет структуру: заголовки секций, первый ряд карточек,
три колонки принципов. Не на каждой секции подряд.

**Прогрессивное улучшение.** Классы состояний ставит JS: пока модуль не загрузился,
страница в статичном читаемом виде. Ни один текст не спрятан за JS.
